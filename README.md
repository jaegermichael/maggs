# Maggs Engineering & Consultancy

React + Vite web app for **Maggs Engineering Group**.

Laser CNC structural design and fabrication: gates, privacy screens, wall cladding, signage, renovations, and general engineering.

## Stack

- React 19 + TypeScript
- Vite 7
- React Router
- Tailwind CSS
- Project photography and interactive React UI
- Framer Motion

## Routes

- `/` Home with project gate and laser scene
- `/about`
- `/services`
- `/portfolio`
- `/configurator` photo-based gate configurator and estimate
- `/process`
- `/contact`
- `/quote`

## Develop

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

The Vercel SPA rewrite is configured in `vercel.json`.
